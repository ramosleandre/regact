# Working directory

Your working directory is your current directory. Reference files by paths relative to it. The provided files are:

```text
__WORKSPACE_TREE__
```

Create scripts freely at the working-directory root; organize supporting modules in your own subdirectories as needed. The framework reads your controller from `controller.py`. __WORKSPACE_EXTENSIONS__Use the provided `framework/` files as-is.
