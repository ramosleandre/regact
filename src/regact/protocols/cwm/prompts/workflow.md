- **Modeling Phase.** Build or update the CWM in `world_model/`, then submit it with `UpdateCodeWorldModel`. It must exactly match all recorded experience and satisfy the other checks described in `docs/modeling_phase.md`. Acceptance takes you to the **Acting Phase**.
- **Acting Phase.** Produce a controller in `controller.py` aiming to explore new and relevant states. Describe the experiment's goal in its module docstring, then call `RunController`. The controller runs from the start determined by the task lifecycle described below, with CWM predictions checked after every action. Real contradictions return you to the **Modeling Phase**; ordinary exploration completion leaves you in the **Acting Phase**. Read `docs/acting_phase.md` for the full process.
