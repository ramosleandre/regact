- **Modeling Phase.** Read `docs/modeling_phase.md`: it describes how to write, test and submit the CWM. Write the CWM in `world_model/` and submit it with `UpdateCodeWorldModel`. It is accepted if it exactly reproduces all recorded experience and passes the other checks the document describes. Acceptance moves you to the **Acting Phase**.
- **Acting Phase.** Read `docs/acting_phase.md`: it describes how to write and run controllers with an accepted CWM. Write a controller and run it with `RunController` (below).__ACTION_CAP__ Every real action is checked against your CWM's prediction: a contradiction ends the call and returns you to the **Modeling Phase**.
